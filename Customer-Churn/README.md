Overview

This Power BI dashboard analyzes customer behavior and predicts churn patterns for a banking dataset.
It provides insights into customer retention, demographics, financial behavior, and risk factors affecting churn.

Key Metrics
Total Customers
Churn Rate %
Average Balance
Active vs Inactive Members
Customer Distribution by Geography
Features
Churn analysis by Geography (France, Germany, Spain)
Churn distribution by Age Groups
Active vs Inactive members breakdown
Financial behavior analysis (Balance, Salary, Balance-to-Salary Ratio)
Interactive filters (Country, Age, Activity Status)
Tools Used
Power BI
Python (for preprocessing & modeling)
Scikit-learn (Logistic Regression model)
Data Visualization
Data Cleaning & Feature Engineering

Insights
Germany has the highest churn rate compared to other countries.
Older customers (50+) show higher probability of churn.
Inactive members are more likely to leave the bank.
Customers with certain product counts show higher exit probability.
